# Simulated TikTok interface walkthrough

[Download the MP4](https://raw.githubusercontent.com/GiftedElephant1/connector/main/docs/demos/Connector-TikTok-Simulated-Walkthrough.mp4)

This 1 minute 57 second video shows Connector 0.6.1's actual interface with a fictional creator and intercepted sample API responses. A simulation label remains visible throughout. It includes captions and no audio. File size: approximately 2.1 MB; format: H.264 MP4, 1280 × 920, compatible yuv420p pixels, 15 fps.

**This is a rehearsal aid, not a qualifying live TikTok sandbox recording.** TikTok sign-in/consent is not performed, all creator/status/analytics responses are simulated, and the website is a local preview rather than the submitted public domain. No personal account was accessed, no TikTok credentials were used, and no TikTok request or publication occurred.

For a review submission, record a real sandbox test account authorizing access and producing actual API results on the website domain supplied to TikTok. Follow the [real sandbox recording guide](../tiktok-review.md#6-record-the-complete-flow-on-windows). This video meets the requested container and file-size constraints; that does not establish TikTok review compliance or approval.
